Our machine learning pipeline uses time, current, and temperature to train multiple models and predict battery voltage.

Abstract

This project applies machine learning techniques to predict battery voltage using real-world charge and discharge data. The dataset includes approximately 7.2 million observations. Models evaluated include linear regression, random forest, KNN, and a neural network. Random forest achieved the best performance.
