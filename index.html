Abstract

This project explores machine learning models to predict battery voltage over time using relative time, current, and temperature as input features. Three models were implemented: linear regression, random forest, and k-nearest neighbors. Model performance was evaluated using R² and RMSE. The random forest model achieved the highest accuracy and lowest prediction error.

Model Performance

R² measures how well the model explains variation in the data. RMSE measures prediction error, where lower values indicate better accuracy.
