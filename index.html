Our machine learning pipeline uses input features including relative time, current, and temperature. The models are evaluated using R² and RMSE, and the best-performing model is selected to predict battery voltage.

Abstract

This project applies machine learning techniques to analyze randomized battery usage data and predict battery voltage behavior over time. The dataset includes approximately 7.2 million observations capturing real-world charge and discharge cycles using features such as relative time, current, and temperature. Three models were implemented: linear regression, random forest, and k-nearest neighbors (KNN). Results show that the random forest model achieved the best performance with the lowest RMSE (~0.107) and highest R² (~0.87), indicating strong predictive capability. In contrast, KNN showed higher error and lower accuracy, highlighting limitations on complex datasets. These findings demonstrate that nonlinear models are more effective for capturing battery behavior and improving prediction accuracy.

Key Observations

  • Voltage fluctuates during charge and discharge cycles
  • Current shows spikes during load changes
  • Temperature varies with battery activity
  • Relationships between variables appear nonlinear

Dataset

The dataset consists of approximately 7.2 million observations collected from randomized battery charge and discharge cycles. It captures real-world battery operating conditions and includes the following features:

  • Relative Time (seconds)
  • Voltage
  • Current
  • Temperature

The data was preprocessed in R, including flattening nested structures, converting values to numeric format, and subsampling for efficient visualization and model training. This resulted in a clean dataset suitable for machine learning analysis.

Results

The three models showed clear differences in performance:

  • Linear Regression (Baseline)
    RMSE: 0.141 | R²: 0.78 — captured general trends but limited by linear assumptions.
  • Random Forest (Best Model)
    RMSE: 0.107 | R²: 0.87 — captured nonlinear relationships and produced the most accurate predictions.
  • K-Nearest Neighbors (KNN)
    RMSE: 0.149 | R²: 0.75 — higher error and struggled with large, complex datasets.

Overall, the random forest model outperformed all other approaches due to its ability to model nonlinear patterns in battery behavior.

Model Performance

  • Linear Regression: R² ≈ 0.82
  • Random Forest: R² ≈ 0.91
  • KNN Model: R² ≈ 0.88

R² measures how well the model explains variation in the data. RMSE measures prediction error, where lower values indicate better accuracy.
